# Wisp phone app (GitHub Pages)

This folder is published by GitHub Pages at https://lucastao638.github.io/Wisp/ and is the phone app used when you're away from home. It's a copy of `remote_page.html` - whenever that file changes, copy it to `docs/index.html` too.

The page holds no data. It finds your computer's current secure address on a private ntfy.sh channel, and every request still needs the secret token from pairing (scan the QR code in Wisp > Phone).
